1. What do permissions mean?

r = 4

Read

Files: view contents. Directories: list filenames (subject to other permissions).

w = 2

Write

Files: modify contents. Directories: create, delete or rename entries when combined with directory execute permission.

x = 1

Execute

Files: run executable programs (when other requirements permit). Directories: enter/traverse the directory.

Three permission groups: Owner = file's owner; Group = members of assigned group; Others = everyone else. For each group, add selected values: Read 4 + Write 2 + Execute 1.

2. Flip the permissions

Each illuminated switch adds its value to that group's number. Try turning all three on for Owner: 4 + 2 + 1 = 7.

3. Read the output of ls -l

The first character tells the file type: - is a regular file, d is a directory. The next 9 positions are owner, group, and others, in that order.

Directory example: drwxr-xr-x is often 755. Directory write and execute together can allow removing entries even when you cannot write the individual file inside (subject to sticky bits, ACLs, and other controls).
