Cloud Solutions Challenge

This simulator follows Pearson's current ITS Cloud Computing objectives. Students practice the advantages and costs of cloud, IaaS/PaaS/SaaS, performance/availability/scalability/reliability, public/private/hybrid cloud, architecture diagrams, VMs, containers, APIs, storage, CI/CD, deployment, monitoring, disaster recovery, governance, privacy, identity, least privilege and encryption.

1. Cloud Concepts

Cloud advantages, IaaS/PaaS/SaaS, cost, ROI, PASR, SLAs, edge computing, availability, reliability, scalability and OTS vs custom solutions.

2. Developing Cloud Architecture

Public/private/hybrid, data flows, shared responsibility, virtualization, serverless, APIs, VM sizing/geography/backups and storage requirements.

3. Cloud Development Life Cycle

Source control, virtual environments, packages, testing, bugs, integration, VMs vs containers, microservices, version control and CI/CD.

4. Deploy the Application

Usage-based pricing, scaling, business continuity, disaster recovery, support, training, logging, monitoring, dashboards and alerts.

5. Cloud Governance

Privacy/regulatory requirements, NIST/ISO awareness, ethics/bias/transparency, IAM/MFA, roles, least privilege, encryption, IDS/IPS and firewalls.
