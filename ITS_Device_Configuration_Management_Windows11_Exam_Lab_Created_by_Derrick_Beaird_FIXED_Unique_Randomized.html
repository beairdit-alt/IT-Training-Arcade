Windows Device Technician Challenge

This simulator teaches and tests the current Information Technology Specialist Device Configuration and Management objectives with a Windows 11 emphasis. It covers computer components, Windows installation/configuration, Active Directory concepts, applications and peripherals, storage and file permissions, Windows security, and troubleshooting.

1. Windows Installation & Configuration

Hardware, Windows setup, local/Microsoft/domain accounts, Active Directory, desktop, accessibility and Windows Update.

2. Features, Applications & Peripherals

Apps, Windows features, Copilot, Registry, USB/video/audio connections, projection and display settings.

3. Data Access & Management

Cloud services, partitions, GPT/MBR, NTFS/FAT32/exFAT, shares, permissions, mapped drives, backup and restore.

4. Device Security

Defender Firewall, MFA, biometrics, Windows Hello, malware/social engineering, antimalware and UAC.

5. Management & Troubleshooting

Event Viewer, Task Manager, Safe Mode, services, Device Manager, drivers, networks, domains and command-line tools.
