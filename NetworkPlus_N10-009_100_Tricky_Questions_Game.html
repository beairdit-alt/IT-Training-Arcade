NETWORK+ CRAM WALL

Use this only after you try the question. The goal is pattern recognition under pressure.

Wi‑Fi

2.4 GHz: range/penetration, crowded. Classic 20 MHz plan: 1/6/11.

5 GHz: more channels/capacity, less range.

dBi = antenna gain. dBm = signal level. -45 dBm is stronger than -80 dBm.

Antennas

Omni = broad around AP. Directional = focus down aisle / building-to-building.

MIMO = multiple spatial streams. Beamforming = steer energy toward client.

Subnet Shortcuts

/24 254 hosts • /25 126 • /26 62 • /27 30 • /28 14 • /29 6 • /30 2.

Block size: /25=128, /26=64, /27=32, /28=16.

VLAN / Switching

Endpoint = access port. Multiple VLANs between devices = trunk. 802.1Q = VLAN tagging.

STP prevents L2 loops. LACP bundles links.

Routing

Longest-prefix match first. Default route = fallback. OSPF = link-state IGP. BGP = inter-AS.

Local works, remote fails → gateway/routing/ACL.

DHCP / DNS / ARP

DHCP = DORA, UDP 67/68. Remote DHCP server → relay/helper.

DNS 53. A=IPv4, AAAA=IPv6, MX=mail, PTR=reverse.

ARP = IPv4 to MAC.

Ports

SSH 22 • DNS 53 • HTTP 80 • NTP 123 • SNMP 161/162 • LDAP 389 • HTTPS 443 • SMB 445 • Syslog 514 • LDAPS 636 • RDP 3389.

Troubleshooting

Identify → theory → test theory → plan → implement/escalate → verify/prevent → document.

Change one thing at a time and verify.

Tools

ping=reachability • traceroute=path • nslookup/dig=DNS • arp=IP/MAC cache • tcpdump=packets • Nmap=host/port discovery • LLDP/CDP=neighbors.

Physical

CRC errors → cable/termination/interference/interface. Attenuation = signal loss over distance. Crosstalk = pair-to-pair interference.

Single-mode = longest fiber distances.

Security

802.1X = port-based NAC. RADIUS = centralized AAA. Evil twin = fake AP. ARP poisoning = forged IP↔MAC mappings.

Performance

Latency = delay. Jitter = variation in delay. Packet loss = missing packets. QoS = prioritize/classify important traffic.
