Network Security Technician Challenge

This simulator targets the Information Technology Specialist Network Security exam, INF-102. It emphasizes hands-on foundational security with client/server operating systems, firewalls, devices, ports, permissions, authentication, encryption, wireless security, auditing, malware protection and secure networking.

1. Defense in Depth

CIA, non-repudiation, threats/risk/vulnerabilities, least privilege, physical security, policies, malware and attacks, backup types.

2. Operating System Security

Hardening, patching, GPO, DNS updates, UAC, MFA, passwords, Run As/sudo, users/groups, Kerberos, permissions, auditing, encryption, TPM and BitLocker.

3. Network Device Security

Wireless security, SSIDs/MAC filtering, firewalls, IDS/IPS, SIEM, filtering, DMZ, NAT/PAT, VPN, IPsec, VLANs, DNSSEC and secure ports.

4. Secure Computing

Email protection, spoofing/phishing/pharming, browser security, cache/private browsing, anti-malware installation, updates, scans, remediation and alerts.
