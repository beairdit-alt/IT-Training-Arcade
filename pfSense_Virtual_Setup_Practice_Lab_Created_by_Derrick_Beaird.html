Ticket 103 — Staff VLAN Dead

VLAN 20 interface exists on parent WAN instead of LAN.

Ticket 104 — Students Reach Staff

A broad PASS any rule is above the Student→Staff block rule.

Ticket 105 — Port Forward Fails

NAT rule exists, but no matching WAN firewall rule was created.

Ticket 106 — Client Gets 169.254.x.x

The VLAN 10 interface is up, but the DHCP server for VLAN 10 is disabled.
