FLDOE standards connection and practical skill coverage

Mapped by topic to the FLDOE 2025–26 networking standards: fundamental networking (01), routing concepts (02), router configuration (03), LAN design (04), VLAN configuration (05), network security (08), remote access (09), IP addressing services (10), and maintenance/support/troubleshooting (11). 04 // Field engineer practice desk

Use these tasks after the guided lab. The purpose is to diagnose the layer where traffic fails, not guess commands until a ping works. This is a teaching simulator; verify model-specific syntax on actual Aruba CX switches.

Evidence-based troubleshooting

Layer 1: Link, optics, cable and LLDP. Layer 2: Access VLAN, trunk allowed VLAN list, STP, MAC learning. Layer 3: Host IP, mask, gateway, SVI state and routes. Policy: Firewall rules and management restrictions.

Important: exit returns one configuration level, while end returns to privileged EXEC. Don't enter another global command while still in VLAN-interface context.


Student sign-off / instructor review
Before completing this exercise, students should be able to explain: where VLAN tags are added or removed; why S1 and S2 need matching VLANs; who owns each VLAN gateway; how to find a blocked STP port; why MAC filtering is not device authentication; and why the running configuration must be saved. Each student should submit their exported report and configuration snapshot.
