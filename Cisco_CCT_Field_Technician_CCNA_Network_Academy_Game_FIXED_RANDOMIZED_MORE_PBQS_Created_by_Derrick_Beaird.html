Start as a Field Technician. Finish as a Network Administrator.

This game combines the current Cisco Certified Technician Field Technician track with the current CCNA. CCT focuses on safely identifying, servicing, replacing, backing up and restoring Cisco hardware. CCNA takes students into actual network configuration, routing, switching, IP services, security and automation.

LEVEL 1 — Cisco CCT Field Technician

800-150

Networking foundations • service tools • Cisco software • infrastructure/collaboration • hardware replacement • UCS/data center.

Heavy emphasis on safe hardware replacement and field-service workflow.

LEVEL 2 — Cisco CCNA

200-301 v1.1

Network fundamentals • network access • IP connectivity • IP services • security fundamentals • automation/programming.

Configuration and troubleshooting of enterprise networking fundamentals.

🔧 Field Tech

Console access, ESD, serial numbers, Catalyst/ISR/Nexus/UCS identification, backup/restore and IOS software handling.

🔀 Switching

VLANs, trunks, STP, EtherChannel, CDP/LLDP, port security and access-layer troubleshooting.

🛰 Routing

IPv4/IPv6, subnetting, routing tables, static routes, OSPF, default routes and packet forwarding.

🧰 Services

DHCP, DNS, NTP, NAT/PAT, SNMP, syslog, QoS and wireless fundamentals.

🛡 Security

SSH, AAA, ACLs, Layer 2 security, VPN concepts and secure device management.

🤖 Automation

REST APIs, JSON, controllers, Ansible/Terraform concepts, AI/ML basics for network operations.
